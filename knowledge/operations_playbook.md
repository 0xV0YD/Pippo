# Operations Playbook

## Scheduling Rule Of Thumb

When scheduling a team sync:
- prefer saved member aliases or saved group names
- use the active selected calendar account
- create a Meet link by default
- confirm before sending invitations

## Linear Rule Of Thumb

When creating a Linear issue:
- put it in the correct team
- assign it explicitly when ownership is clear
- set workflow state intentionally
- use labels for category, not for workflow state

## Knowledge Rule Of Thumb

When Pippo later answers from the knowledge base:
- retrieved sources should be preferred over model guesswork
- answers should mention where the information came from
- short grounded answers are better than confident invented answers

## Security Rule Of Thumb

Only the authorized Telegram identity should be able to drive the bot.

High-impact actions should keep confirmation in the loop even if intent looks obvious.
