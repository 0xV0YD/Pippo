# Pippo RAG Learning Plan

## Phase 0: Corpus and Mental Model

Goal:
- define what Pippo should know before building retrieval

Deliverables:
- `knowledge/` folder
- a few markdown docs with clear structure
- shared vocabulary for project, glossary, notes, and playbooks

What to understand:
- RAG is the knowledge layer
- MCP is the capability layer
- retrieval only works well if source docs are clean

Exit criteria:
- Pippo has a starter knowledge corpus
- docs are split by topic
- headings and dates exist where useful
